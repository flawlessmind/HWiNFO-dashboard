# HWiNFO Dashboard

Локальный веб-дашборд для анализа CSV-логов датчиков **HWiNFO**. Приложение на Python и Flask строит интерактивные графики, рассчитывает сводную статистику по сенсорам и позволяет подготовить отчёт в PDF через диалог печати браузера.

## Возможности

- Интерактивные временные графики на базе Plotly.
- Группировка параметров по категориям: процессор, видеокарта, производительность, память, материнская плата, диски, сеть, троттлинг, ошибки, пределы и другие показатели.
- Статистика по числовым сенсорам: среднее значение, минимум, максимум и стандартное отклонение.
- Подсчёт значений «Да» и «Нет» для булевых датчиков.
- Краткая сводка по системе: загрузка, температура и потребление CPU/GPU, использование VRAM и ОЗУ — если соответствующие сенсоры есть в CSV.
- Экспорт сводной таблицы в `summary.csv`.
- Подготовка PDF-отчёта через встроенную печать браузера. Настройки печати страницы задаются в HTML/CSS; итоговая пагинация может немного отличаться в разных браузерах.
- Работа на локальном компьютере: Flask-сервер слушает `127.0.0.1`.

## Как это выглядит

После запуска приложение открывается в браузере. В верхней части отображаются имя исходного файла, количество обработанных строк и длительность лога. Ниже доступны краткий вывод по системе, вкладки с категориями датчиков, графики и таблицы со статистикой.

## Требования

- Python 3.9 или новее.
- Flask.
- Современный браузер, например Chrome, Edge или Firefox.
- Подключение к интернету для загрузки Plotly с CDN. Без доступа к CDN интерактивные графики могут не загрузиться.

## Установка

Склонируйте репозиторий или скачайте исходные файлы. Перейдите в папку проекта и установите зависимость:

```bash
python -m pip install Flask
```

В Windows также можно использовать команду `py` вместо `python`:

```powershell
py -m pip install Flask
```

### Структура проекта

```text
.
├── app.py
├── README.md
└── templates/
    └── index.html
```

## Запуск

Передайте приложению путь к CSV-файлу, экспортированному HWiNFO.

**Windows (PowerShell или CMD):**

```powershell
py app.py "C:\путь\к\HWiNFO.csv"
```

**Linux / macOS:**

```bash
python3 app.py "/путь/к/HWiNFO.csv"
```

По умолчанию приложение использует порт `8000` и пытается открыть дашборд в браузере автоматически. Если нужно выбрать другой порт:

```powershell
py app.py "C:\путь\к\HWiNFO.csv" --port 8080
```

После запуска откройте адрес, указанный в консоли, например:

```text
http://127.0.0.1:8000
```

Чтобы остановить приложение, нажмите `Ctrl+C` в терминале, где запущен Flask.

## Подготовка CSV в HWiNFO

1. Запустите логирование датчиков в HWiNFO и сохраните лог в CSV.
2. Убедитесь, что в файле есть строки измерений с датой и временем, а также столбцы нужных датчиков.
3. Передайте путь к сохранённому файлу при запуске `app.py`.

Парсер рассчитан на CSV с датой в формате `ДД.ММ.ГГГГ` и временем в формате `ЧЧ:ММ:СС` или `ЧЧ:ММ:СС.ffffff`. Имена столбцов используются для определения категорий и построения некоторых заранее настроенных графиков. Поэтому отдельные графики или строки сводки могут отсутствовать, если нужный сенсор не записывался, называется иначе или отсутствует в логе.

## Использование дашборда

- Переключайте вкладки категорий, чтобы просматривать соответствующие графики и таблицы.
- В таблицах числовых датчиков представлены среднее, минимальное и максимальное значение, а также стандартное отклонение.
- Для булевых сенсоров отображаются количества значений «Да» и «Нет».
- Кнопка **«Скачать summary.csv»** формирует файл со статистикой. Он использует разделитель `;` и кодировку UTF-8 с BOM для удобного открытия в Excel.

## Экспорт в PDF

1. Нажмите **«Скачать PDF-отчёт»** на странице дашборда.
2. В системном диалоге печати выберите **«Сохранить как PDF»** или аналогичный пункт.
3. Используйте формат бумаги **A4** и альбомную ориентацию, если эти настройки доступны.
4. При необходимости включите печать фоновой графики, чтобы сохранить цвета графиков.
5. Проверьте предварительный просмотр перед сохранением: браузеры могут по-разному разбивать длинные таблицы и графики на страницы.

PDF создаётся средствами браузера; отдельный генератор PDF на стороне Python не используется.

## Известные ограничения

- Для сводки и графиков используются названия сенсоров, заданные в коде. Если HWiNFO записывает другой вариант названия, потребуется добавить его в `app.py`.
- Датчики, отсутствующие в CSV или не содержащие числовых/булевых значений, не дают статистики.
- Plotly загружается из CDN, поэтому для работы графиков необходимо соединение с интернетом, если библиотека не размещена локально.
- Вёрстка и пагинация PDF зависят от используемого браузера и его параметров печати.

## Конфиденциальность

Приложение запускается локально и читает указанный CSV на вашем компьютере. Для отображения графиков браузер загружает библиотеку Plotly с CDN; сам CSV-файл приложением на удалённый сервер не отправляется.
